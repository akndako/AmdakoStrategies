# Custom Domain Deployment Checklist\n\n## Pre-Deployment\n\n- [ ] Domain purchased and registered\n- [ ] DNS pointed to hosting provider\n- [ ] Hosting account with Node.js support\n- [ ] SSH/terminal access verified\n- [ ] MongoDB Atlas account created (or local MongoDB available)\n- [ ] Code committed and pushed to repository\n\n## Server Preparation\n\n- [ ] Node.js v20+ installed\n- [ ] npm installed and working\n- [ ] PM2 installed globally\n- [ ] Web server installed (Nginx or Apache)\n- [ ] SSH key access configured\n- [ ] Firewall rules updated (ports 80, 443 open)\n\n## Code Deployment\n\n- [ ] Repository cloned to server\n- [ ] `.env` file created on server (NOT committed to git)\n- [ ] All required environment variables set:\n  - [ ] `NODE_ENV=production`\n  - [ ] `MONGO_URI` configured\n  - [ ] `JWT_SECRET` generated (use: `openssl rand -base64 32`)\n  - [ ] `FRONTEND_URL` set to `https://yourdomain.com`\n  - [ ] `VITE_API_URL` configured\n- [ ] Dependencies installed: `npm ci --only=production`\n- [ ] Frontend built: `npm run build`\n- [ ] `dist/` folder created with files\n\n## Backend Deployment\n\n- [ ] PM2 started: `pm2 start server.js --name \"amdako-api\"`\n- [ ] PM2 configured for auto-start: `pm2 startup` and `pm2 save`\n- [ ] Backend running on port 3000 (or configured port)\n- [ ] Health check passing: `curl http://localhost:3000/health`\n- [ ] Logs checked for errors: `pm2 logs amdako-api`\n\n## Frontend Deployment\n\n- [ ] Web server configured (Nginx/Apache)\n- [ ] `dist/` folder served from correct location\n- [ ] SPA routing configured (fallback to `index.html`)\n- [ ] Static files being served correctly\n- [ ] API proxy routes configured\n\n## SSL/HTTPS Setup\n\n- [ ] SSL certificate generated (Let's Encrypt)\n- [ ] Certificate renewed (auto-renewal configured)\n- [ ] HTTPS enabled in web server config\n- [ ] HTTP redirects to HTTPS\n- [ ] SSL certificate valid and trusted\n\n## Testing\n\n- [ ] Frontend loads at `https://yourdomain.com`\n- [ ] `www.yourdomain.com` redirects correctly\n- [ ] Health endpoint works: `curl https://yourdomain.com/health`\n- [ ] Login page loads and functions\n- [ ] API calls work from browser console\n- [ ] No CORS errors in browser console\n- [ ] All images and assets load\n- [ ] Forms submit successfully\n- [ ] Error pages display correctly\n- [ ] Mobile responsiveness verified\n\n## Security Verification\n\n- [ ] `.env` file has restricted permissions (600)\n- [ ] `.env` file NOT accessible via web\n- [ ] Rate limiting working (check headers)\n- [ ] Security headers present (Helmet.js)\n- [ ] CORS properly configured\n- [ ] Input validation working\n- [ ] Password hashing verified in database\n- [ ] JWT tokens working\n- [ ] No sensitive data in logs\n- [ ] No console.logs in production code\n\n## Performance Verification\n\n- [ ] Frontend bundle size reasonable\n- [ ] Gzip compression enabled\n- [ ] Cache headers set for static files\n- [ ] Page load time acceptable\n- [ ] No memory leaks in PM2\n- [ ] Database queries optimized\n- [ ] No 500 errors in backend logs\n\n## Monitoring Setup\n\n- [ ] PM2 monitoring dashboard enabled: `pm2 web`\n- [ ] Log rotation configured\n- [ ] Backup strategy in place\n- [ ] Database backups automated\n- [ ] Alert system configured (optional)\n- [ ] Uptime monitoring enabled (optional)\n\n## DNS & Domain Verification\n\n- [ ] DNS propagation complete\n- [ ] `nslookup yourdomain.com` returns correct IP\n- [ ] Domain resolves to server\n- [ ] WWW subdomain redirects\n- [ ] Mail records configured (if needed)\n\n## Post-Deployment\n\n- [ ] All team members can access\n- [ ] Backup of database made\n- [ ] Deployment documented\n- [ ] Update process documented\n- [ ] Rollback procedure tested\n- [ ] 24/7 monitoring active\n- [ ] Incident response plan ready\n\n## First Week Monitoring\n\n- [ ] Check logs daily\n- [ ] Monitor for errors\n- [ ] Test all user flows\n- [ ] Check certificate expiration\n- [ ] Verify backups working\n- [ ] Monitor performance metrics\n\n## Sign-Off\n\n- **Deployed By:** ___________________\n- **Date:** ___________________\n-
